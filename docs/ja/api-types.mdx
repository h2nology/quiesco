メソッドのシグネチャに出てくるすべての型と、Quiescoのソースでの宣言です。`import type { … } from '@quiesco/core'` でインポートします。
アプリ内で使う型は `@quiesco/agent`、ランナーのオプションは各ランナーのパッケージから。文字列のユニオン型（`Direction`、`Permission` …）は[定数](./api-constants)を見てください。

```ts
interface ElementQuery {
  /** testID：完全一致の文字列またはRegExp。 */
  id?: TextQuery;
  /** 要素のサブツリーのテキスト（一致する最も深い要素が返される）。 */
  text?: TextQuery;
  /** accessibilityLabel / aria-label。 */
  label?: TextQuery;
  /** accessibilityRole / role。 */
  role?: string;
  /** セマンティック型（`'button'`、`'input'`、`'switch'` …：どのプラットフォームでも同じ）、ホストコンポーネントの型（`'RCTView'`、`'div'`）、または要素をレンダリングするコンポーネントのdisplayName。 */
  type?: SemanticType | (string & {});
  /** 子孫のいずれかが一致する（Detoxの `withDescendant`）。 */
  has?: ElementQuery | string;
  /** 要素自身は一致しない。 */
  not?: ElementQuery | string;
  /** このマッチャーに一致する唯一の要素の内側（Detoxの `withAncestor`）。 */
  within?: ElementQuery | string;
  /** n番目の一致（0始まり）。レンダリング順で、どのプラットフォームでも同じ順序。 */
  index?: number;
}
```
