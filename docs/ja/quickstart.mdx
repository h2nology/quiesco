---
title: "クイックスタート（Web）"
description: "新しいExpoアプリから、Chromiumでテストが通るまでを約10分で。"
---

必要なもの：Node.js 24+、SDK 55以降のExpoアプリ（`npx create-expo-app@latest`）。

<Steps>
  <Step title="プロジェクトをセットアップする">
    <CodeGroup>
    ```sh pnpm
    cd my-app

    # 依存パッケージ、config plugin、Metro、エントリーファイル、quiesco.config.mts、最初のテスト
    pnpm dlx quiesco init
    ```
    ```sh npm
    cd my-app

    # 依存パッケージ、config plugin、Metro、エントリーファイル、quiesco.config.mts、最初のテスト
    npx quiesco init
    ```
    ```sh bun
    cd my-app

    # 依存パッケージ、config plugin、Metro、エントリーファイル、quiesco.config.mts、最初のテスト
    bunx quiesco init
    ```
    ```sh yarn
    cd my-app

    # 依存パッケージ、config plugin、Metro、エントリーファイル、quiesco.config.mts、最初のテスト
    yarn dlx quiesco init
    ```
    </CodeGroup>

    `init`はどのテストランナーを使うかを尋ねます。Enterを押すとVitest（推奨）になり、JestかCucumberも選べます（[テストランナー](./runners)）。`--runner vitest|jest|cucumber`を付けると、質問なしで選べます。以下の手順はVitestを前提にしています。ほかのランナーでもファイル名が違うだけです。
  </Step>
  <Step title="ルートレイアウトをラップする">
    ルートレイアウトを`<QuiescoRoot>`でラップします（デフォルトテンプレートでは`src/app/_layout.tsx`）。

    ```tsx
    import { QuiescoRoot } from '@quiesco/agent';

    export default function TabLayout() {
      // …
      return (
        <QuiescoRoot>
          <ThemeProvider value={colorScheme === 'dark' ? DarkTheme : DefaultTheme}>…</ThemeProvider>
        </QuiescoRoot>
      );
    }
    ```
  </Step>
  <Step title="ホーム画面にテストIDを付ける">
    `src/app/index.tsx`で`<ThemedView style={styles.container} testID="home">`とします。生成された`e2e/app.test.ts`は、これが表示されていることを確認します。

    ```ts
    import { test } from '@quiesco/vitest';

    test('the home screen is shown', async ({ app }) => {
      await app.expectVisible({ id: 'home' });
    });
    ```
  </Step>
  <Step title="（任意）ホーム画面を落ち着かせる">
    このステップが必要なのは、ホーム画面に動き続けるアニメーションがある場合だけです。Quiescoは画面が落ち着くのを待ってから次に進むため、数分続くアニメーションがあると`SYNC_TIMEOUT`まで待ち続けます。そうしたアニメーションがなければ、このステップは飛ばしてください。

    SDK 55のデフォルトテンプレートがその一例で、ホーム画面で装飾用の光（glow）を4分間回し続けます。以降のバージョンのテンプレートにこのアニメーションがあるとは限らないので、自分のプロジェクトで確認してください。対処は、この要素にテストIDを付け、落ち着いたかどうかの判定からQuiescoに外させることです。

    `src/components/animated-icon.web.tsx`（iOS / Android向けには`animated-icon.tsx`も）で：

    ```tsx
    <Animated.View … style={styles.glow} testID="logo-glow">
    ```

    続いて、`quiesco.config.mts`のこの行のコメントを外します。

    ```ts
    sync: { ignoreElements: ['logo-glow'] },
    ```
  </Step>
  <Step title="実行する">
    <CodeGroup>
    ```sh pnpm
    pnpm exec playwright install chromium

    # EXPO_PUBLIC_QUIESCO=1でWebビルドをエクスポートしてから quiesco test --platform web
    pnpm e2e:web
    ```
    ```sh npm
    npx playwright install chromium

    # EXPO_PUBLIC_QUIESCO=1でWebビルドをエクスポートしてから quiesco test --platform web
    npm run e2e:web
    ```
    ```sh bun
    bunx playwright install chromium

    # EXPO_PUBLIC_QUIESCO=1でWebビルドをエクスポートしてから quiesco test --platform web
    bun run e2e:web
    ```
    ```sh yarn
    yarn playwright install chromium

    # EXPO_PUBLIC_QUIESCO=1でWebビルドをエクスポートしてから quiesco test --platform web
    yarn e2e:web
    ```
    </CodeGroup>

    テンプレートはサーバー側でレンダリングします（`web.output: "server"`）。このエクスポートに対しては、Quiescoが`npx expo serve`を自動で実行します。静的エクスポートはそのまま配信されます。
  </Step>
</Steps>

`npx quiesco doctor`はセットアップを確認し、足りないものの直し方を示します。`npx quiesco tree`は実行中のアプリの要素ツリーを出力するので、テストIDを探すのに使えます。
