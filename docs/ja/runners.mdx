---
title: "JestとVitest"
description: "Cucumberの代わりにJestやVitestからQuiescoを使います。"
---

`@quiesco/vitest`と`@quiesco/jest`は、`@quiesco/cucumber`がCucumberに対して行うことをVitestとJestに対して行います。実行全体で1つのセッション（デバイスとアプリ）を使い、各テストの前にリセットし、別のプラットフォームやブラウザー向けのタグが付いたテストはスキップし（`@ios`、`@android`、`@web`、`@native`、`@chromium`、`@firefox`、`@webkit`。最も内側の階層が優先されます）、失敗時のメッセージには証跡ファイル（スクリーンショット、要素ツリー、アイドル状態、ログ）が列挙されます。

## Vitest {#vitest}

`app`はテストフィクスチャーです。

```ts
// vitest.config.ts
import { quiesco, quiescoPlugin } from '@quiesco/vitest/config';
import { defineConfig } from 'vitest/config';
export default defineConfig({ plugins: [quiescoPlugin()], test: { ...quiesco(), include: ['e2e/**/*.test.ts'] } });

// e2e/todo.test.ts
import { test } from '@quiesco/vitest';

test('a new todo appears at the top', async ({ app }) => {
  await app.tap('add-todo');                      // アプリがアイドルになるまで待ってからタップ
  await app.type('todo-title', 'Buy milk');
  await app.tap({ role: 'button', text: 'Save' });
  await app.expectText({ id: 'todo-item', index: 0 }, 'Buy milk');
});
test('Android only', { tags: ['@android'] }, async ({ app }) => { /* … */ });
```

`quiesco()`はファイルをまたいでアプリを保持し（`isolate: false`）、ファイルを1つずつ実行し（`quiesco({ workers: N })`ならN台のデバイスで実行）、プラットフォームタグを宣言します。`quiescoPlugin()`は実行の進捗を`quiesco test`の進捗バーと`quiesco ui`に送ります。レポーターを追加するのはこの2つがVitestを実行するときだけで、自分で設定したレポーターもそのまま残ります。

## Jest {#jest}

プリセットです。テストからはグローバルの`quiesco`を通じてアプリにアクセスします。

```js
// jest.config.js
module.exports = { preset: '@quiesco/jest', maxWorkers: 1, testTimeout: 120_000 }; // maxWorkers: N = N台のデバイス

// e2e/todo.test.js
test('a new todo appears at the top @ios', async () => {
  await quiesco.app.tap('add-todo');
});
```

プラットフォームタグはテストまたは`describe`のタイトルに書きます（Jestにはテストオプションがないため）。プリセットは、実行の進捗を`quiesco test`と`quiesco ui`に送るレポーターも追加します。設定に独自の`reporters`があるとプリセットのものを置き換えるので、そこに`'@quiesco/jest/reporter'`を追加してください（`'default'`と並べて）。

## 実行 {#running}

どちらも`npx quiesco test --platform ios --runner vitest|jest`で実行するか、[`quiesco ui`](./ui)を使ってブラウザから実行します。両方のサンプルが[examples/todo-app/e2e](https://github.com/h2nology/quiesco/tree/main/examples/todo-app/e2e)にあります。詳しくは[CucumberなしでQuiescoを使う](./api#using-quiesco-without-cucumber)を、複数のデバイスで同時に実行する方法は[並列実行](./parallel)を参照してください。
