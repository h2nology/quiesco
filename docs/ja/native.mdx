---
title: "iOSとAndroid"
description: "e2eアプリをビルドし、同じfeatureをiOSシミュレーターとAndroidエミュレーターで実行します。"
---

ネイティブでの実行には、アプリのe2eビルドが必要です（`EXPO_PUBLIC_QUIESCO=1`付きでビルドしたもので、エージェントと`@quiesco/native`を含みます）。

```sh
npx expo install expo-dev-client
npx quiesco build ios       # または：npx quiesco build android
npx quiesco test --platform ios
```

`quiesco build`は`EXPO_PUBLIC_QUIESCO=1`付きの`expo prebuild`とネイティブビルド（シミュレーター向けの`xcodebuild`、`gradlew assembleDebug`）を実行し、`quiesco.config.mts`の`binaryPath`の場所にアプリを書き出します（生成された設定には一般的なパスが入っています）。前回からアプリの設定と依存関係が変わっていなければDebugビルドは省略します。`--force`を付けると必ずビルドします。`quiesco test`は、dev clientがMetroを必要とし`devClient.metroUrl`で何も応答しないとき、`EXPO_PUBLIC_QUIESCO=1`付きでMetroを起動し、実行の終わりに停止します。自分で起動したMetroはそのまま使います（[設定](./api#configuration)の`devServer`）。

`devices`でエミュレーター / シミュレーターを指定します（[設定](./api#configuration)を参照）。CIでは、`EXPO_PUBLIC_QUIESCO=1`を付けたEASビルドプロファイルで同じe2eビルドを作れます。3つのプラットフォームすべてで動作確認済みの完全なセットアップは[サンプルアプリ](./example-app)を参照してください。

プラットフォーム間で異なる点（入力、権限、システムダイアログ）は[プラットフォームの違い](./platforms)にまとめています。
