Quiesco用の汎用cucumberステップです（任意）。中国語、日本語、英語で書けます。

<Warning>
**要件ではなく操作手順です。** これらのステップが表すのはタップや文字（「`login-button`をタップする」）であり、ユーザーが達成したいことではありません。プロトタイピングやアプリの調査で使ってください。実際のプロジェクトでは、`this.app`（または独自のdriver。[Driverパターン](./driver-pattern)を参照）の上にビジネスの言葉で独自のステップ（「When the user logs in as …」）を書きます。そうすれば、UIが変わってもfeatureは要件を表し続けます。
</Warning>

## 使い方 {#use}

```ts
// features/support/steps.ts
import { registerQuiescoSteps } from '@quiesco/steps';

registerQuiescoSteps(); // すべての言語。または { languages: ['ja'] }、{ only: ['tap', 'seeText'] }
```

`@quiesco/cucumber/register`もimportする必要があります（`this.app`を提供します）。ステップはcucumberのキーワードに依存しない`defineStep`で登録されるため、どのキーワード（`当` / `もし` / `When` …）の後でも、どの`# language:`のfeatureファイルでも動作します。

引用符で囲んだ対象は**testID**です。「テキスト」系のステップは、代わりに表示されているテキストにマッチします。どのステップも、他のQuiescoの呼び出しと同じくアプリがアイドルになるのを待ちます。スリープは不要です。

`pressBack`はiOSでは使えません（戻るボタンがないため）。iOSではQuiescoが`ACTION_NOT_SUPPORTED`を報告します。

一部のステップは、引用符付きの値の代わりに単語を取ります（どの言語の単語も、すべての言語で使えます）。

| 単語 | 値 |
|---|---|
| 方向（`scroll`、`swipe`：スワイプでは指を動かす方向） | 上 下 左 右 / up down left right |
| 端（`scrollToEdge`） | 顶部 底部 最左边 最右边 / 一番上 一番下 左端 右端 / top bottom left right |
| 画面の向き | 竖屏 横屏 / 縦向き 横向き / portrait landscape |
| 外観 | 浅色 深色 / ライト ダーク / light dark |
| 権限 | 相机 麦克风 定位 通知 通讯录 照片 日历 / カメラ マイク 位置情報 通知 連絡先 写真 カレンダー / camera microphone location notifications contacts photos calendar |

未知の単語を使うと、受け付ける単語の一覧を添えてステップが失敗します。デバイスとシステムのステップ（`background`、`orientation`、`offline`、`grantPermission`、`allowDialog`、`shake`、…）は`this.app.device`を呼び出します。プラットフォームが対応していない操作については、Quiescoが理由を添えて`ACTION_NOT_SUPPORTED`を報告します（[プラットフォームの違い](./platforms)）。
