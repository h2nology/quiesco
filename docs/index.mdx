title: "Quiesco"
description: "Gray-box end-to-end testing for Expo apps on iOS, Android and the web, driven by Vitest, Jest, Cucumber or any other Node.js test runner."
---

A small agent inside the e2e build of your app tells the test runner when the app is idle — no pending
network requests, timers, React renders or animations — so tests never sleep and never poll. The same
tests run unchanged on an iOS simulator, an Android emulator and in the browser (Chromium, Firefox, WebKit). Vitest
(recommended), Jest and Cucumber get ready-made integrations (`@quiesco/vitest`, `@quiesco/jest`,
`@quiesco/cucumber`; [test runners](./runners)).

```ts
import { test } from '@quiesco/vitest';

test('a new todo appears at the top of the list', async ({ app }) => {
  await app.backdoor('loginAs', 'a@example.com');             // state set up without driving the UI
  await app.tap('add-todo');                                  // waits until the app is idle, then taps
  await app.type('todo-title', 'Buy milk');
  await app.tap({ role: 'button', text: 'Save' });
  await app.expectText({ id: 'todo-item', index: 0 }, 'Buy milk');
});
```

## Features {#features}

- **Automatic synchronization** — network, timers, React scheduler, idle callbacks, native transitions
  and a frame-stability fallback ([how it works](./sync)). A sync timeout names what was still busy.
- **Real input** — touches and text through `@quiesco/native` (iOS / Android) or Playwright (web); a
  callback mode (`js`) works without native code.
- **Fast resets** — a soft reset (storage, your reset hooks, remount) before every test, typically
  ~200 ms; `@hard-reset` relaunches the app.
- **Backdoors** — set up state from tests without driving the UI (`app.backdoor('loginAs', …)`).
- **Nothing in production** — without `EXPO_PUBLIC_QUIESCO=1` the agent is replaced by a no-op stub and
  the native module is excluded from the build (checked in CI).

## Packages {#packages}

| Package | What it is |
|---|---|
| `quiesco` | CLI: `init`, `build`, `test` (with a progress bar), `ui`, `list`, `doctor`, `tree`, `devices` ([CLI](./cli)) |
| `@quiesco/agent` | In-app agent: element queries, sync trackers, actions, reset, backdoors; `withQuiesco()` for Metro |
| `@quiesco/native` | Expo module for real touches and text input on iOS / Android (e2e builds only) |
| `@quiesco/expo-plugin` | Config plugin: excludes the native module from production builds, allows the local connection in e2e builds |
| `@quiesco/core` | Host side: WebSocket server, `Driver` (the `app` of a test), sessions, iOS / Android device providers. Runner-independent |
| `@quiesco/vitest` | Vitest: `test` with the `app` fixture, `quiesco()` config, `quiescoPlugin()` |
| `@quiesco/jest` | Jest: preset with the Quiesco test environment, global `quiesco` |
| `@quiesco/cucumber` | cucumber-js World (`this.app`) and lifecycle hooks |
| `@quiesco/web` | Web device provider (Playwright library) |
| `@quiesco/ui` | The [test UI](./ui) behind `quiesco ui` |
| `@quiesco/steps` | Optional generic steps in Chinese, Japanese and English — for prototyping only ([steps](./steps)) |
| `@quiesco/protocol` | Types and constants shared by agent and host |

The source is on [GitHub](https://github.com/h2nology/quiesco) under the MIT license.
