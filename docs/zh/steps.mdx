Quiesco 的可选通用 cucumber 步骤，提供中文、日文和英文版本。

<Warning>
**这是操作脚本，不是需求。** 这些步骤描述的是点击和文本（"tap `login-button`"），而不是用户想要达成的目标。请在做原型或探索 App 时使用它们。正式项目应在 `this.app` 之上——或在自己的 driver 之上（见 [Driver 模式](./driver-pattern)）——用业务语言编写自己的步骤（"When the user logs in as …"），这样即使 UI 变化，feature 文件描述的仍然是需求。
</Warning>

## 使用 {#use}

```ts
// features/support/steps.ts
import { registerQuiescoSteps } from '@quiesco/steps';

registerQuiescoSteps(); // 所有语言；或 { languages: ['ja'] }、{ only: ['tap', 'seeText'] }
```

还必须导入 `@quiesco/cucumber/register`（它提供 `this.app`）。这些步骤通过 cucumber 与关键字无关的 `defineStep` 注册，因此可以跟在任何关键字之后（`当` / `もし` / `When` …），也可用于任何 `# language:` 的 feature 文件。

带引号的目标是 **testID**；"文本" 类步骤则匹配显示的文本。每个步骤都会像其他 Quiesco 调用一样等待 App 空闲——不需要 sleep。

| `pressBack` | `按返回键` | `戻るボタンを押す` | `I press back` |
| `openUrl` | `打开链接 "myapp://todos"` | `リンク "myapp://todos" を開く` | `I open the link "myapp://todos"` |

| `swipe` | `在 "todo-item" 上向左滑动` | `"todo-item" を左にスワイプする` | `I swipe left on "todo-item"` |
| `drag` | `把 "item-1" 拖到 "item-3"` | `"item-1" を "item-3" までドラッグする` | `I drag "item-1" to "item-3"` |
| `pinch` | `在 "photo" 上双指缩放到 2 倍` | `"photo" を 2 倍にピンチする` | `I pinch "photo" to 2 times` |
| `setSlider` | `把滑块 "volume" 设为 30` | `スライダー "volume" を 30 にする` | `I set the slider "volume" to 30` |
| `switchOn` | `打开开关 "notify"` | `スイッチ "notify" をオンにする` | `I turn on the switch "notify"` |
| `switchOff` | `关闭开关 "notify"` | `スイッチ "notify" をオフにする` | `I turn off the switch "notify"` |
| `select` | `在 "priority" 中选择 "高"` | `"priority" で "高" を選ぶ` | `I select "High" in "priority"` |

| `foreground` | `把 App 切回前台` | `アプリをフォアグラウンドに戻す` | `I bring the app to the foreground` |
| `relaunch` | `重新启动 App` | `アプリを再起動する` | `I relaunch the app` |
| `orientation` | `把设备转到横屏` | `画面を横向きにする` | `I rotate the device to landscape` |
| `appearance` | `把外观设为深色模式` | `外観をダークモードにする` | `I switch to dark mode` |

`pressBack` 在 iOS 上不可用（没有返回键）；Quiesco 会在 iOS 上报告 `ACTION_NOT_SUPPORTED`。

有些步骤接受一个词而不是带引号的值（任何一种语言的词在所有语言中都可用）：

| 词 | 取值 |
|---|---|
| 方向（`scroll`、`swipe`：swipe 时为手指移动的方向） | 上 下 左 右 / up down left right |
| 边缘（`scrollToEdge`） | 顶部 底部 最左边 最右边 / 一番上 一番下 左端 右端 / top bottom left right |
| 屏幕方向 | 竖屏 横屏 / 縦向き 横向き / portrait landscape |
| 外观 | 浅色 深色 / ライト ダーク / light dark |
| 权限 | 相机 麦克风 定位 通知 通讯录 照片 日历 / カメラ マイク 位置情報 通知 連絡先 写真 カレンダー / camera microphone location notifications contacts photos calendar |

遇到未知的词时，步骤会失败，并列出可接受的词。设备和系统步骤（`background`、`orientation`、`offline`、`grantPermission`、`allowDialog`、`shake` …）调用 `this.app.device`；某个平台做不到的操作，Quiesco 会报告 `ACTION_NOT_SUPPORTED` 并附上原因（[平台差异](./platforms)）。
