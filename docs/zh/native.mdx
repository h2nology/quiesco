---
title: "iOS 和 Android"
description: "构建 e2e App，在 iOS 模拟器和 Android 模拟器上运行同样的 feature。"
---

原生平台的运行需要 App 的 e2e 构建（以 `EXPO_PUBLIC_QUIESCO=1` 构建，因此其中包含 agent和 `@quiesco/native`）：

```sh
npx expo install expo-dev-client
EXPO_PUBLIC_QUIESCO=1 npx expo prebuild --clean
# Android：debug APK（dev client）
(cd android && ./gradlew assembleDebug)
# iOS：模拟器构建（dev client）
xcodebuild -workspace ios/<App>.xcworkspace -scheme <App> -configuration Debug \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' -derivedDataPath ios/build build

EXPO_PUBLIC_QUIESCO=1 npx expo start --dev-client   # Metro，在另一个终端中运行
npm run e2e:android       # 或：npm run e2e:ios
```

将 `quiesco.config.mts` 中的 `binaryPath` 指向构建产物（生成的配置里已填好常用路径），并在`devices` 中设置 Android Emulator / iOS Simulator（见 [配置](./api#configuration)）。在 CI 中，带 `EXPO_PUBLIC_QUIESCO=1` 的 EAS 构建配置（build profile）会产出同样的 e2e 构建；完整且经过测试的三平台配置见 [示例 App ](./example-app)。

各平台之间的差异（输入、权限、系统弹窗）见 [平台差异](./platforms)。
