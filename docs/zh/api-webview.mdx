---
title: "WebView"
description: "查找、点击、输入和检查 App 内所显示网页中的元素，并在页面中运行脚本。"
---

`app.webview()` 用于访问 WebView 中所显示页面的元素：iOS / Android 上是 react-native-webview，web 上是 `<iframe>`。react-native-webview 没有 web 实现，因此 App 在 web 上要自己渲染一个 iframe，例如在 `MyWebView.web.tsx` 中。

```ts
const help = app.webview('help');

await help.element({ css: '#name' }).type('Bob');
await help.element({ text: 'Say hello' }).tap();
await help.element({ id: 'result' }).expectText('Hello, Bob');
```

- **每个调用都会等待** App 空闲、页面稳定：加载完成，且页面没有正在进行的 `fetch` / `XMLHttpRequest`（由 Quiesco 注入页面的脚本统计）。页面的定时器不被跟踪；反正断言会一直重试到超时。
- **只处理 WebView 的主框架：** 页面内的 iframe 和 shadow DOM 无法访问。
- **iOS 和 Android 需要 `@quiesco/native`**：脚本通过原生 WebView 运行，因此 App 中无需 `onMessage`。没有它时，调用会以 `ACTION_NOT_SUPPORTED` 失败。

每个方法都接受 `timeoutMs` 和 `sync` [调用选项](./api#call-options) 作为最后一个参数。

## 查找页面及其元素 {#finding}

### `webview(target?)` {#webview}

```ts
webview(target?: MatcherInput): WebView
```

类型： [`MatcherInput`](./api-types#matcherinput) · [`WebView`](./api-webview#webview)

与 `target` 匹配的 WebView，可以是任意 [匹配器](./api-matchers)，例如它的 testID。不传参数时，取屏幕上唯一的那个 WebView。

```ts
const help = app.webview('help');

// 屏幕上唯一的 WebView
const page = app.webview();
```

### `element(query)` {#element}

```ts
element(query: WebElementQuery): WebElement
```

类型： [`WebElementQuery`](./api-types#webelementquery) · [`WebElement`](./api-webview#element)

页面中的一个元素。`query` 恰好包含 `css`、`xpath`、`id` 或 `text` 中的一个，多个元素匹配时还可以加上 `index`。

```ts
help.element({ css: '#name' });
help.element({ xpath: '//input[@name="name"]' });
help.element({ id: 'result' });

// 元素文本（空白合并后），精确匹配
help.element({ text: 'Say hello' });
help.element({ text: /^Loading/ });

// 多个匹配中的第二个
help.element({ css: '.faq-item', index: 1 });
```

| 字段 | 含义 |
|---|---|
| `css` | CSS 选择器 |
| `xpath` | XPath 表达式 |
| `id` | 元素的 `id` 属性 |
| `text` | 元素文本（空白合并后）的精确匹配，或一个 RegExp。取最内层的匹配元素 |
| `index` | 第几个匹配，从 `0` 开始 |

## 操作元素 {#actions}

### `tap(options?)` {#tap}

```ts
tap(options?: CallOptions): Promise<PageElement>
```

类型： [`CallOptions`](./api-types#calloptions) · [`PageElement`](./api-types#pageelement)

先将元素滚入视图，再进行一次真实点击：iOS / Android 上在元素的屏幕位置触摸，web 上使用 Playwright 输入。

```ts
await help.element({ text: 'Contact us' }).tap();
```

| 选项 | 默认值 | 含义 |
|---|---|---|
| `timeoutMs` | `sync.timeoutMs`（10 秒） | 等待页面稳定、元素出现的最长时间 |
| `sync` | `true` | `false`：这次调用前后不等待 App 空闲（[通用选项](./api#call-options)） |

多个元素匹配时立即以 `MULTIPLE_MATCHES` 失败；超时内没有出现可见且启用的匹配时以 `ELEMENT_NOT_FOUND` 失败。

### `type(text, options?)` {#type}


```ts

```

| 选项 | 默认值 | 含义 |
|---|---|---|

## 页面 {#the-page}

### `runScript(body, args?, options?)` {#runscript}

```ts
runScript<T extends JsonValue = JsonValue>(
  body: string,
  args?: JsonValue[],
  options?: CallOptions,
): Promise<T>
```

类型： [`JsonValue`](./api-types#jsonvalue) · [`CallOptions`](./api-types#calloptions)

在页面中运行一个函数体，并以 JSON 返回其值。`args` 作为 `arguments` 传入；返回的 promise 会被 await。

```ts
const title = await help.runScript<string>('return document.title');

const count = await help.runScript<number>(
  'return document.querySelectorAll(arguments[0]).length',
  ['.faq-item'],
);

// promise 会被 await
const status = await help.runScript<number>('return fetch("/api/ping").then((r) => r.status)');
```

| 选项 | 默认值 | 含义 |
|---|---|---|
| `timeoutMs` | `sync.timeoutMs`（10 秒） | 等待页面稳定、元素出现的最长时间 |
| `sync` | `true` | `false`：这次调用前后不等待 App 空闲（[通用选项](./api#call-options)） |

页面中的异常会让调用以 `APP_ERROR` 失败。`runScript` 使用 `new Function`，页面的 Content-Security-Policy 可能会禁止它。
