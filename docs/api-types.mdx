Every type a method's signature names, with its declaration as written in Quiesco's source. Import them with
`import type { … } from '@quiesco/core'`; the in-app types come from `@quiesco/agent`, the runner options from
the runner's package. The string unions (`Direction`, `Permission` …) are [constants](./api-constants).

## Matchers {#matchers}

### `MatcherInput` {#matcherinput}

```ts
type MatcherInput = ElementQuery | string;
```

### `ElementQuery` {#elementquery}

```ts
interface ElementQuery {
  /** testID: exact string or RegExp. */
  id?: TextQuery;
  /** Text of the element's subtree (the deepest matching element is returned). */
  text?: TextQuery;
  /** accessibilityLabel / aria-label. */
  label?: TextQuery;
  /** accessibilityRole / role. */
  role?: string;
  /**
   * A semantic type (`'button'`, `'input'`, `'switch'`, ...: the same on every platform), a host
   * component type (`'RCTView'`, `'div'`) or the displayName of a component rendering the element.
   */
  type?: SemanticType | (string & {});
  /** Some descendant matches (Detox `withDescendant`). */
  has?: ElementQuery | string;
  /** The element itself does not match. */
  not?: ElementQuery | string;
  /** Inside the single element matched by this matcher (Detox `withAncestor`). */
  within?: ElementQuery | string;
  /** n-th match (0-based) in render order, the same order on every platform. */
  index?: number;
}
```

## Results {#results}

### `ElementSummary` {#elementsummary}

```ts
/** What the agent reports about a matched element. */
interface ElementSummary {
  /** Host component type, e.g. `RCTView`, `RCTText`, `div`. */
  type: string;
  testID?: string;
  text: string;
  role?: string;
  label?: string;
  rect: Rect | null;
  visible: boolean;
  /**
   * Visible fraction of the element's area (0–1): the part inside the window and inside every
   * ancestor that clips its content (scroll views, `overflow: hidden`). 0 when hidden by style.
   */
  visibleRatio: number;
  /** Platform-independent kind, when the element is one of SEMANTIC_TYPES. */
  semanticType?: SemanticType;
  /** Has the input focus (text inputs; the focused DOM element on the web). */
  focused: boolean;
  /** False when disabled (`disabled`, `accessibilityState.disabled`, `aria-disabled`, `editable={false}`). */
  enabled: boolean;
  /** Checked state of switches, checkboxes and radios (`accessibilityState.checked`, `aria-checked`, Switch `value`). */
  checked?: boolean | 'mixed';
  /** Current value: TextInput text, Switch / Slider / Picker value, or `accessibilityValue`. */
  value?: JsonValue;
  /** Serializable subset of the element's props (functions and React elements are dropped). */
  props: Record<string, JsonValue>;
}
```

### `TrackerState` {#trackerstate}

```ts
/** State of one idle tracker. */
interface TrackerState {
  name: string;
  idle: boolean;
  /** Human-readable busy reasons, e.g. `GET https://api.example.com/todos (1200ms)`. */
  busy: string[];
  /**
   * frame-stable only samples while a call waits, so after a sync timeout it reports idle: these are its
   * busy reasons when the latest wait for idle ended while the element tree was still changing.
   */
  lastWait?: string[];
  /**
   * In a SYNC_TIMEOUT: the tracker was idle at the timeout but busy this many ms before it,
   * and `busy` is what it was busy with then.
   */
  idleForMs?: number;
}
```

### `RegisterOptions` {#registeroptions}

```ts
interface RegisterOptions extends LifecycleOptions {
  /**
   * Use your own World (must extend QuiescoWorld). Default QuiescoWorld. A plain constructor type, not
   * `typeof QuiescoWorld`: that one is generic over the world parameters, which no subclass satisfies.
   */
  world?: new (options: IWorldOptions<any>) => QuiescoWorld<any>;
  /** Default step timeout. Each driver call has its own sync timeout; this caps a whole step. Default 60 s. */
  stepTimeoutMs?: number;
  /** BeforeAll timeout: booting an emulator can take minutes. Default 10 min. */
  setupTimeoutMs?: number;
  /**
   * Timeout of the per-scenario reset (Before). It can start the app again when it is gone, which waits up to
   * 3 × the connect timeout. Default 3 min.
   */
  resetTimeoutMs?: number;
}
```

### `LifecycleOptions` {#lifecycleoptions}

```ts
interface LifecycleOptions {
  /** Config instead of loading `quiesco.config.*` (QUIESCO_CONFIG picks another file). */

}
```
