# 场景逐项数据

## 读法

- **耗时**：单位为秒，只统计通过的运行，不含每个场景开始前的状态重置。“重置”一列单独给出重置耗时的中位数。
- **p90**：第 90 百分位数。分位数都用线性插值（R type 7）计算。
- **失败率区间**：95% Wilson 区间。N = 20 时，0 次失败的区间上限是 16.1%，所以区间重叠的工具之间不能断言谁更稳定。
- **跳过**：工具做不到这个操作（例如 Detox 不能操作通知和 Android 系统权限弹窗）。跳过不算失败。
- **全部失败**：20 次都没有通过，所以没有耗时数据。
- **整套耗时**：比较的是“共同场景集”（iOS 去掉 S21 / S22，Android 去掉 S10b / S22），保证四个工具比的是同一组场景。
