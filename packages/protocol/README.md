# @quiesco/protocol

Types and constants shared by the Quiesco agent (in the app) and host (in the test run): JSON-RPC
messages, matchers, error codes and the protocol version. Installed as a dependency of the other Quiesco
packages; you do not need it directly.

Part of [Quiesco](https://github.com/h2nology/quiesco): gray-box end-to-end testing for Expo apps on iOS, Android and the web. Setup: `npx quiesco init` ([quick start](https://github.com/h2nology/quiesco#quick-start-web-about-10-minutes)).
